# قوالب Pro

مصدر القوالب الاحترافية المضمّنة في `www/index.html`.

- `kit.css` و`kit.js`: نظام التصميم المشترك (الألوان، والمكونات، والأيقونات SVG، والدوال).
- `t/*.html`: كل قالب (أول سطر META فيه الاسم والوصف واللون والثيم). القوالب ذات التطبيقين ملفان: `.0` للزبون و`.1` للإدارة.
- `build.py`: يبني كل قالب كملف HTML كامل في `out/` للمعاينة.
- `embed.py`: يولّد كتلة الجافاسكربت (`out/block.js`) التي تُضاف إلى `www/index.html`.
